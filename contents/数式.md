## 数式（Math Expressions）

論文や技術文書に向けた、LaTeX記法による美しい数式表示。

### 1. インライン数式

文章の途中に数式を埋め込むための形式。前後にドル記号を1つずつ配置。

アインシュタインの有名な数式は $E = mc^2$ である。

```markdown
アインシュタインの有名な数式は $E = mc^2$ である。

```

### 2. ディスプレイ数式（独立行）

数式を中央揃えにして、独立した行として大きく強調表示する形式。前後にドル記号を2つずつ配置。

$$f(x) = \int_{-\infty}^{\infty} \hat{f}(\xi) e^{2\pi i x \xi} d\xi$$

```markdown
$$f(x) = \int_{-\infty}^{\infty} \hat{f}(\xi) e^{2\pi i x \xi} d\xi$$

```

### 3. 上付き文字・下付き文字

べき乗や添え字を表現するための基本記法。上付きは `^`、下付きは `_` を使用。

$x_{i}^{2} + y_{i}^{2} = z_{i}^{2}$

```markdown
$x_{i}^{2} + y_{i}^{2} = z_{i}^{2}$

```

### 4. 分数

複雑な分子・分母の関係を縦に並べて見やすく整理する記法。`\frac{分子}{分母}` の形で指定。

$$\frac{\partial f}{\partial x} = \lim_{\Delta x \to 0} \frac{f(x + \Delta x) - f(x)}{\Delta x}$$

```markdown
$$\frac{\partial f}{\partial x} = \lim_{\Delta x \to 0} \frac{f(x + \Delta x) - f(x)}{\Delta x}$$

```

### 5. 行列

数や記号を縦横の格子状に配置する記法。`matrix` や `pmatrix`（丸括弧付き）などの環境を使用。

$$A = \begin{pmatrix} a & b \\ c & d \end{pmatrix}$$

```markdown
$$A = \begin{pmatrix} a & b \\ c & d \end{pmatrix}$$

```

### 6. 総和・積分・極限

`\sum`・`\int`・`\lim` の範囲は `_` と `^` で指定。

$$\sum_{k=1}^{n} k = \frac{n(n+1)}{2}, \qquad \int_{0}^{\pi} \sin x \, dx = 2, \qquad \lim_{n \to \infty} \left(1 + \frac{1}{n}\right)^{n} = e$$

```markdown
$$\sum_{k=1}^{n} k = \frac{n(n+1)}{2}, \qquad \int_{0}^{\pi} \sin x \, dx = 2, \qquad \lim_{n \to \infty} \left(1 + \frac{1}{n}\right)^{n} = e$$

```

### 7. 場合分け・複数行の揃え

`cases` で場合分け、`aligned` で `&` の位置を揃えた複数行の式。改行は `\\`。

$$|x| = \begin{cases} x & (x \ge 0) \\ -x & (x < 0) \end{cases}$$

$$\begin{aligned} (a+b)^2 &= (a+b)(a+b) \\ &= a^2 + 2ab + b^2 \end{aligned}$$

```markdown
$$|x| = \begin{cases} x & (x \ge 0) \\ -x & (x < 0) \end{cases}$$

$$\begin{aligned} (a+b)^2 &= (a+b)(a+b) \\ &= a^2 + 2ab + b^2 \end{aligned}$$

```

| `\times \div \pm` | $\times \div \pm$ | `\to \Rightarrow` | $\to \Rightarrow$ |
| `\sqrt{x}` | $\sqrt{x}$ | `\in \subset \cup \cap` | $\in \subset \cup \cap$ |
| `\vec{v}` | $\vec{v}$ | `\infty \partial \nabla` | $\infty \partial \nabla$ |
