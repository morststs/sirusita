テキストベースの図解（Diagrams as Code）ツール「D2（Declarative Diagramming）」の基本構文や特徴をカテゴリー別にまとめました。

---

## 1. 基本構文・ノードの作成

* **`x: テキスト`**：ノード（要素）の作成とラベル名の指定
* **`x.y: テキスト`**：ネスト（入れ子）構造によるコンテナ（枠）と内部要素の表現
* **`"半角スペース あり": テキスト`**：文字列をダブルクォーテーションで囲むことによる、スペースを含むIDの定義

```d2
server: Web サーバー
db: データベース
"ログ 収集": ログ収集
cloud: クラウド {
  app: アプリ
  cache: キャッシュ
}
```

---

## 2. 接続（エッジ）

* **`->`**：単方向の矢印による接続
* **`<-`**：逆方向の矢印による接続
* **`<->`**：双方向の矢印による接続
* **`--`**：矢印のない直線による接続
* **`x -> y: ラベル名`**：接続線（エッジ）へのテキストの追加

```d2
a: クライアント
b: API
c: 認証
d: ストレージ
a -> b: リクエスト
b <- c: トークン
b <-> d: 読み書き
c -- d: 同じ VPC
```

---

## 3. スタイリング・デザイン

* **`style.fill: "#カラーコード"`**：ノードの背景色の変更
* **`style.stroke: "#カラーコード"`**：ノードの枠線色の変更
* **`style.stroke-width: 数字`**：枠線の太さの指定
* **`style.shadow: true`**：ノードへのドロップシャドウ（影）の追加
* **`style.border-radius: 数字`**：ノードの角の丸み調整

```d2
ok: 正常 {
  style.fill: "#1e4620"
  style.stroke: "#4caf50"
  style.stroke-width: 3
  style.border-radius: 8
}
ng: 異常 {
  style.fill: "#5c1e1e"
  style.stroke: "#f44336"
  style.shadow: true
}
ok -> ng: 障害発生 {
  style.stroke: "#ff9800"
  style.stroke-dash: 4
}
```

---

## 4. 形状（シェイプ）の変更

* **`shape: rectangle`**：一般的な長方形（デフォルト）
* **`shape: circle`**：真円の表現
* **`shape: cylinder`**：データベース等を表す円柱の表現
* **`shape: person`**：ユーザーやアクターを表す人型の表現
* **`shape: cloud`**：ネットワークや外部サービスを表す雲型の表現

```d2
user: 利用者 {shape: person}
web: Web {shape: rectangle}
lb: 振り分け {shape: circle}
db: DB {shape: cylinder}
ext: 外部サービス {shape: cloud}
user -> web -> lb -> db
lb -> ext
```

---

## 5. アイコン・画像の埋め込み

* **`icon: https://...`**：Web上の画像URLを指定したアイコンの表示
* **`icon: ./path/to/image.png`**：ローカルの画像パスを指定したアイコンの表示

> `icon:` に URL を指定した画像は、プレビューを表示したときにその URL から読み込まれます。オフラインのときはアイコンが表示されません（図自体は描画されます）。

---

## 6. 特殊な図解（SQL・テキスト）

* **`shape: sql_table`**：型やキーを指定できるリレーショナルデータベースのテーブル表現
* **`shape: code`**：ノード内にソースコードやプレーンテキストをそのまま綺麗に表示するブロック設定

```d2
users: {
  shape: sql_table
  id: int {constraint: primary_key}
  name: varchar(64)
  email: varchar(255) {constraint: unique}
}
notes: {
  shape: sql_table
  id: int {constraint: primary_key}
  user_id: int {constraint: foreign_key}
  title: text
}
notes.user_id -> users.id
```

```d2
hello: |go
  func main() {
      fmt.Println("hello")
  }
|
```

---

## 7. レイアウトの向き・入れ子

* **`direction: right`**：図全体の流れる向き（`up` / `down` / `left` / `right`）
* **`x: { ... }`**：波括弧の中に書いた要素は x の中（コンテナ）に入る
* **`x.y -> z.w`**：コンテナの中の要素どうしも `.` でつなげる

```d2
direction: right
フロント: {
  画面
  状態管理
}
バックエンド: {
  API
  DB: {shape: cylinder}
}
フロント.画面 -> フロント.状態管理
フロント.状態管理 -> バックエンド.API: fetch
バックエンド.API -> バックエンド.DB
```
